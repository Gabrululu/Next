# Next indexer (Envio HyperIndex)

Indexes the v3 `Next` and `NextPass` contracts on Monad testnet (chain 10143) via HyperSync, with the Monad RPC as a fallback.
Built from the official `envio init` template (envio 3.14.0).

**Entities:**
- `Campaign`, `Registration`, `Draw`, `Winner`, `Pass`
- `CampaignBlockStat`: registrations per block, which feed the live stress panel
- `CampaignStats`
- `GlobalStats`

Aggregates are computed at index time because Envio Cloud does not expose GraphQL aggregate queries.

## Commands

Envio does not run natively on Windows. Use WSL 2, Node ≥ 22 and pnpm 10.

```bash
pnpm install
pnpm codegen      # after any change to config.yaml / schema.graphql
pnpm typecheck
pnpm test         # simulated events, no network needed
pnpm dev          # local run: needs Docker and ENVIO_API_TOKEN in .env (see .env.example); Hasura at http://localhost:8080
```

ABIs in `abis/` are generated by `scripts/gen-abi.mjs`. Do not edit them by hand.

## Deploy to Envio Cloud

Source: https://docs.envio.dev/docs/HyperIndex/hosted-service-deployment

1. Go to https://envio.dev/app, sign in with GitHub, and install the Envio Deployments GitHub App on the repo.
2. Click Add Indexer and set:
   - root directory `indexer`
   - config file `config.yaml`
   - your deployment branch
3. Push to that branch. Cloud deployments don't need an API token. The optional `ENVIO_*` overrides are listed in `.env.example`.
4. Copy the GraphQL endpoint into the web app as `NEXT_PUBLIC_ENVIO_GRAPHQL_URL`.
